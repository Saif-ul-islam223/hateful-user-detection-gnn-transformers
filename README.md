# hateful-user-detection-gnn-transformers
End‑to‑end hateful user detection system using classical machine learning, transformer embeddings (BERT/RoBERTa), and Graph Neural Networks (GCN &amp; GraphSAGE). Includes text embedding generation, cosine‑similarity graph construction, model training, evaluation (ROC‑AUC &amp; F1), and analysis of model performance on imbalanced social network data.
